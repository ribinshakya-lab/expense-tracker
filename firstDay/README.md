# Expense Tracker
A simple web app to track you daily expense 
#installation
1. clone the repo:
 ```bash
 git clone https://github.com/ribinshakya-lab/expense-tracker1.git
 ```
 
2. open 'index.html' in your browser

## Usage
1. Enter and **amount**, pick a category**, and add an optional **description**
2. Click **Submit** to add the expense to the table.
3. Click **delete** to remove an expense.
